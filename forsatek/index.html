How a room gets recorded

There is no dataset to buy. So we collect it.

A Dubai hospitality licence says nothing about a doorway. The autism certification belongs to IBCCES. The Dubai Code is a building minimum, not a guest experience. So the information is collected property by property, against the same field list every time.

  1. 1

    Start from the property's own records

    We ask the hotel for its accessible room types against a fixed schema, not for a paragraph of description.

  2. 2

    Attribute by attribute

    Door widths in centimetres, shower thresholds, transfer space, bed height. The same fields for every property, so two hotels can be compared.

  3. 3

    Every field carries its state

    Confirmed by the property, unconfirmed, contradicted, or declined. We collect what the property knows. We do not run inspections.

  4. 4

    Only sourced fields are published

    A value with no source and no date does not reach the traveller, and the AI cannot answer from it.
